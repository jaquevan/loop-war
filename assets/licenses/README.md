# Licenses

One file per sound, named `<cardId>.md`. Every card in the catalog needs one
before it ships. This is the record you produce if an asset is ever disputed.

```
cardId:      kick_001
displayName: Hard Kick
source:      stock | premium | community
origin:      pack name, URL, or "recorded by <name>"
license:     CC0 | royalty-free (pack license) | original work
acquiredOn:  YYYY-MM-DD
attestation: community uploads only - Roblox userId + date of ownership attestation
reviewedBy:  who listened to it before approval
notes:
```
